# EG13 M2 (Sources) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the Digital Oscillator (Braids), Modal Synth (Elements), Resonator (Rings) and Audio Input source engines, an engine selector that remembers each engine's settings, input conversion to each engine's native rate, the per-part Input source selector (external / other part / both) with "Other part only" output routing, the EG13 FX init patch, and a CPU benchmark.

**Architecture:** Every voice preallocates all five source engines, each inside its own `NativeRateWrapper`. The wrapper now also converts the host input to the engine's native rate and pads every engine to one common latency per plugin kind (note onsets for the instrument, the input path for EG13 FX). The Synth keeps a per-part, per-engine stash of P1–P8 values: switching engines swaps them and tells the host. Parts can take the other part's output as their input (A→B with no delay, B→A one block later, through a soft limiter). State moves to schema 3 with the engine stash.

**Tech Stack:** C++17, CMake + Ninja, Catch2 v3, r8brain-free-src 7.6, upstream pichenettes/eurorack (Plaits, Braids, Elements, Rings + stmlib, unmodified; stmlib random shadowed by `third_party/eurorack-patches`), CLAP 1.2.10, clap-wrapper v0.16.0.

**Spec:** `docs/superpowers/specs/2026-10-20-eg13-design.md` (M2 row of §11; §2.3 audio input and other-part input; §3 engines; §4 catalogue; §5 voice and part; §6 FX init patch; §7 parameters and state; §10 CPU budget).

**Branch:** `m2-sources`, stacked on `m1-synth-architecture` (not yet merged to main).

## Global Constraints

- EG13 is GPL-3.0. Never use "Mutable Instruments" or module names in the UI or product; engines show traditional names: **Macro Oscillator**, **Digital Oscillator**, **Modal Synth**, **Resonator**, **Audio Input**.
- macOS 14+ deployment target, universal binary (arm64 + x86_64). C++17. `/core` builds and tests on macOS and Linux (CI: GCC 13, `-Werror` on `eg13_core`).
- The audio thread never allocates, locks or waits. Allocation happens only in constructors and `prepare`. Prove it with `eg13::test::ScopedAllocationCounter` (read `counter.count()` into a local before `REQUIRE`).

## Scope notes (decisions where the spec is silent)

- **Engine parameter maps** (P1–P8; the slot has 8 host parameters):
  - Digital Oscillator: Shape (47), Timbre, Color, Frequency (±12 st), Signature, Bit Depth (2/3/4/6/8/12/16), Sample Rate (4k…96k). Braids' own AD envelope and quantizer are not exposed (M4 envelopes replace them). A one-pole VCA (as in Braids' firmware) follows the gate and velocity so notes end.
  - Modal Synth: Model (Modal/String/Strings), Bow, Blow, Strike, Geometry, Brightness, Damping, Position. Fixed at Elements' defaults: contour 1, timbres/flow/mallet 0.5, signature 0, Space 0.5 (stereo spread, no reverb — reverb arrives as Part FX in M5). Input excites the resonator through Elements' strike input.
  - Resonator: Model (Modal/Sympathetic/String/FM Voice/Sympathetic Q/String + Reverb), Structure, Brightness, Damping, Position, Exciter (Internal/Input), Frequency (±12 st), Spread (mono sum ↔ odd left / even right). One Rings resonator per voice (polyphony 1); a note-on strums it.
  - Audio Input: Gain (−24…+12 dB), Attack (1 ms…2 s), Release (5 ms…5 s): the input through a per-voice AR gate.
- **Latency per plugin kind:** the instrument aligns note onsets (≈2.3 ms); EG13 FX aligns the input path (≈2.8 ms) so Dry and processed input line up. Every engine in a voice is padded to that one value.
- **Engine switch while a note sounds:** the old engine is cut and, if the key is still held, the new engine starts the note. No crossfade in M2.
- **EG13 FX init patch for M2:** Part A Source = Audio Input, Trigger = Always on, Dry 0, master level 1.0 (so it still passes audio at unity). Filter and Granular from spec §6 arrive in M3/M5. M1 FX projects keep their sound: documents older than schema 3 get Source = Macro Oscillator explicitly (their P values belong to it).
- **Other-part feeds** always pass a soft limiter (transparent below ±1, asymptote ±2), so loops cannot run away.
- **Per-voice input conversion:** each voice converts the input for its active engine (only the active engine runs). The benchmark task measures the cost.

```cpp
#pragma once

#include <cstddef>
#include <memory>
#include <vector>

#include "engine/voice_engine.h"

namespace r8b {
class CDSPResampler24;
}

namespace eg13 {

// Runs an engine at its native sample rate and block size, converting its
// output (and, for engines that read input, the host input) with r8brain.
// At the native rate it is a bit-exact pass-through. Notes and parameters
// reach the engine at native block boundaries (the hardware's control rate).
// nativeRate <= 0 runs the engine at the host rate.
class NativeRateWrapper final : public VoiceEngine {
 public:
  // ~2.3 ms of latency at every common host rate (r8brain 7.6, measured).
  static constexpr double kTransitionBandPercent = 30.0;

  NativeRateWrapper(std::unique_ptr<VoiceEngine> inner, double nativeRate, int nativeBlock);
  ~NativeRateWrapper() override;

  void prepare(double hostRate, int maxBlock) override;  // main thread
  void reset() override;
  void noteOn(float note, float velocity) override;
  void noteOff() override;
  void setNote(float note) override;
  // in: host-rate input (nullable = silence); converted for engines that use it.
  void process(const float* const* in, float* const* out, const ParamValues& p,
               int n) override;
  const EngineInfo& info() const override;

  void setExtraDelay(int samples);  // main thread, after prepare (allocates)

  int outputLatencySamples() const { return latency_; }
  int inputLatencySamples() const { return inputLatency_; }
  int extraDelaySamples() const { return extra_; }
  int latencySamples() const { return latency_ + extra_; }
  int inputPathLatencySamples() const { return inputLatency_ + extra_; }
  size_t inputUnderruns() const { return underruns_; }

 private:
  void pushInput(const float* const* in, int n);
  void renderNativeBlock(const ParamValues& p);
  void applyExtraDelay(float* const* out, int n);

  std::unique_ptr<VoiceEngine> inner_;
  double nativeRate_;
  int nativeBlock_;
  bool bypass_ = true;
  bool usesInput_ = false;
  int latency_ = 0;
  int inputLatency_ = 0;

  // Output path: native -> host.
  std::unique_ptr<r8b::CDSPResampler24> resampler_[2];
  std::vector<float> native_[2];
  std::vector<double> scratch_;
  std::vector<float> fifo_[2];
  size_t fifoRead_ = 0;
  size_t fifoSize_ = 0;
  size_t zeroPad_ = 0;  // host samples of silence owed after reset()

  // Input path: host -> native.
  std::unique_ptr<r8b::CDSPResampler24> inputResampler_[2];
  std::vector<double> inputScratch_;
  std::vector<float> inputFifo_[2];  // ring buffer
  size_t inputRead_ = 0;
  size_t inputSize_ = 0;
  size_t inputPrime_ = 0;  // native samples of silence queued at reset()
  std::vector<float> nativeIn_[2];
  size_t underruns_ = 0;

  // Alignment delay.
  int extra_ = 0;
  std::vector<float> delay_[2];
  size_t delayPos_ = 0;
};

}  // namespace eg13
```

```cpp
#include "engine/native_rate_wrapper.h"

#include <algorithm>
#include <cmath>
#include <utility>

#include "CDSPResampler.h"

namespace eg13 {

NativeRateWrapper::NativeRateWrapper(std::unique_ptr<VoiceEngine> inner, double nativeRate,
                                     int nativeBlock)
    : inner_(std::move(inner)), nativeRate_(nativeRate), nativeBlock_(nativeBlock) {}

NativeRateWrapper::~NativeRateWrapper() = default;

void NativeRateWrapper::prepare(double hostRate, int maxBlock) {
  const double native = nativeRate_ > 0.0 ? nativeRate_ : hostRate;
  inner_->prepare(native, nativeBlock_);
  bypass_ = std::fabs(hostRate - native) < 1e-6;
  usesInput_ = inner_->info().usesInput;
  latency_ = 0;
  inputLatency_ = 0;
  inputPrime_ = 0;
  scratch_.assign(size_t(nativeBlock_), 0.0);
  inputScratch_.assign(size_t(maxBlock), 0.0);
  for (int ch = 0; ch < 2; ++ch) {
    resampler_[ch].reset();
    inputResampler_[ch].reset();
    native_[ch].assign(size_t(nativeBlock_), 0.0f);
    nativeIn_[ch].assign(size_t(nativeBlock_), 0.0f);
    fifo_[ch].clear();
    inputFifo_[ch].clear();
  }
  if (!bypass_) {
    for (int ch = 0; ch < 2; ++ch) {
      resampler_[ch] = std::make_unique<r8b::CDSPResampler24>(native, hostRate, nativeBlock_,
                                                              kTransitionBandPercent);
      fifo_[ch].assign(size_t(resampler_[ch]->getMaxOutLen(nativeBlock_)), 0.0f);
    }
    latency_ = int(std::lround(double(resampler_[0]->getInLenBeforeOutPos(0)) * hostRate / native));
    if (usesInput_) {
      for (int ch = 0; ch < 2; ++ch) {
        inputResampler_[ch] = std::make_unique<r8b::CDSPResampler24>(hostRate, native, maxBlock,
                                                                     kTransitionBandPercent);
      }
      // The input converter withholds `withheld` host samples. Queue enough
      // native silence that the engine never waits for input.
      const int withheld = inputResampler_[0]->getInLenBeforeOutPos(0);
      const double lead = double(withheld - latency_) * native / hostRate;
      inputPrime_ = size_t(2 * nativeBlock_ + std::max(0, int(std::ceil(lead))) + 1);
      const size_t capacity = inputPrime_ + size_t(inputResampler_[0]->getMaxOutLen(maxBlock)) +
                              size_t(nativeBlock_);
      for (int ch = 0; ch < 2; ++ch) inputFifo_[ch].assign(capacity, 0.0f);
      inputLatency_ = std::max(
          0, latency_ + int(std::lround(double(inputPrime_) * hostRate / native)) - withheld);
    }
  }
  extra_ = 0;
  for (auto& line : delay_) line.clear();
  reset();
}

void NativeRateWrapper::setExtraDelay(int samples) {
  extra_ = std::max(0, samples);
  for (auto& line : delay_) line.assign(size_t(extra_), 0.0f);
  delayPos_ = 0;
}

void NativeRateWrapper::reset() {
  inner_->reset();
  for (auto& resampler : resampler_) {
    if (resampler) resampler->clear();
  }
  for (auto& resampler : inputResampler_) {
    if (resampler) resampler->clear();
  }
  fifoRead_ = 0;
  fifoSize_ = 0;
  // r8brain skips its own latency after clear(); pad so the onset lands at
  // latencySamples() like it does in steady state.
  zeroPad_ = bypass_ ? 0 : size_t(latency_);
  inputRead_ = 0;
  inputSize_ = inputPrime_;
  for (auto& ring : inputFifo_) std::fill(ring.begin(), ring.end(), 0.0f);
  underruns_ = 0;
  for (auto& line : delay_) std::fill(line.begin(), line.end(), 0.0f);
  delayPos_ = 0;
}

void NativeRateWrapper::noteOn(float note, float velocity) { inner_->noteOn(note, velocity); }

void NativeRateWrapper::noteOff() { inner_->noteOff(); }

void NativeRateWrapper::setNote(float note) { inner_->setNote(note); }

const EngineInfo& NativeRateWrapper::info() const { return inner_->info(); }

void NativeRateWrapper::process(const float* const* in, float* const* out, const ParamValues& p,
                                int n) {
  if (bypass_) {
    inner_->process(usesInput_ ? in : nullptr, out, p, n);
  } else {
    if (usesInput_) pushInput(in, n);
    for (int i = 0; i < n; ++i) {
      if (zeroPad_ > 0) {
        out[0][i] = 0.0f;
        out[1][i] = 0.0f;
        --zeroPad_;
        continue;
      }
      // The converter withholds its first outputs, so a block can yield nothing.
      while (fifoSize_ == 0) renderNativeBlock(p);
      out[0][i] = fifo_[0][fifoRead_];
      out[1][i] = fifo_[1][fifoRead_];
      ++fifoRead_;
      --fifoSize_;
    }
  }
  if (extra_ > 0) applyExtraDelay(out, n);
}

void NativeRateWrapper::pushInput(const float* const* in, int n) {
  const size_t capacity = inputFifo_[0].size();
  int produced = 0;
  for (int ch = 0; ch < 2; ++ch) {
    for (int i = 0; i < n; ++i) inputScratch_[size_t(i)] = in ? double(in[ch][i]) : 0.0;
    double* converted = nullptr;
    produced = inputResampler_[ch]->process(inputScratch_.data(), n, converted);
    for (int j = 0; j < produced; ++j) {
      inputFifo_[ch][(inputRead_ + inputSize_ + size_t(j)) % capacity] = float(converted[j]);
    }
  }
  inputSize_ = std::min(capacity, inputSize_ + size_t(produced));
}

void NativeRateWrapper::renderNativeBlock(const ParamValues& p) {
  const float* nativeIn[2] = {nullptr, nullptr};
  if (usesInput_) {
    const size_t capacity = inputFifo_[0].size();
    const size_t take = std::min(inputSize_, size_t(nativeBlock_));
    if (take < size_t(nativeBlock_)) ++underruns_;
    for (int ch = 0; ch < 2; ++ch) {
      for (size_t j = 0; j < size_t(nativeBlock_); ++j) {
        nativeIn_[ch][j] = j < take ? inputFifo_[ch][(inputRead_ + j) % capacity] : 0.0f;
      }
    }
    inputRead_ = (inputRead_ + take) % capacity;
    inputSize_ -= take;
    nativeIn[0] = nativeIn_[0].data();
    nativeIn[1] = nativeIn_[1].data();
  }
  float* native[2] = {native_[0].data(), native_[1].data()};
  inner_->process(usesInput_ ? nativeIn : nullptr, native, p, nativeBlock_);
  int produced = 0;
  for (int ch = 0; ch < 2; ++ch) {
    for (int j = 0; j < nativeBlock_; ++j) scratch_[size_t(j)] = double(native_[ch][size_t(j)]);
    double* converted = nullptr;
    // Both channels see identical block lengths, so they produce the same count.
    produced = resampler_[ch]->process(scratch_.data(), nativeBlock_, converted);
    for (int j = 0; j < produced; ++j) fifo_[ch][size_t(j)] = float(converted[j]);
  }
  fifoRead_ = 0;
  fifoSize_ = size_t(produced);
}

void NativeRateWrapper::applyExtraDelay(float* const* out, int n) {
  for (int i = 0; i < n; ++i) {
    for (int ch = 0; ch < 2; ++ch) {
      const float delayed = delay_[ch][delayPos_];
      delay_[ch][delayPos_] = out[ch][i];
      out[ch][i] = delayed;
    }
    delayPos_ = (delayPos_ + 1) % size_t(extra_);
  }
}

}  // namespace eg13
```

```cpp
const char* const kShapeNames[BraidsEngine::kNumShapes] = {

    "Square Sub",    "Saw Sub",        "Square Sync",    "Saw Sync",       "Triple Saw",

    "Wave Paraphonic", "Filtered Noise", "Twin Peaks",   "Clocked Noise",  "Granular Cloud",
    "Particle Noise", "Digital Mod",
};

// Braids firmware (braids.cc): RESOLUTION_2..16_BIT and SAMPLE_RATE_4K..96K.
const uint16_t kBitMasks[7] = {0xc000, 0xe000, 0xf000, 0xf800, 0xff00, 0xfff0, 0xffff};
const int kBitDepths[7] = {2, 3, 4, 6, 8, 12, 16};
const int kDecimation[7] = {24, 12, 6, 4, 3, 2, 1};
const int kRatesKHz[7] = {4, 8, 16, 24, 32, 48, 96};

int stepIndex(float normalized, int steps) {
  const int i = int(clamp01(normalized) * float(steps));
  return i < steps ? i : steps - 1;
}

void formatShape(float v, char* buf, size_t size) {
  std::snprintf(buf, size, "%s", kShapeNames[BraidsEngine::shapeIndex(v)]);
}
void formatPercent(float v, char* buf, size_t size) {
  std::snprintf(buf, size, "%d%%", int(std::lround(clamp01(v) * 100.0f)));
}
void formatSemitones(float v, char* buf, size_t size) {
  std::snprintf(buf, size, "%+.1f st", double(BraidsEngine::frequencyOffset(v)));
}
void formatBits(float v, char* buf, size_t size) {
  std::snprintf(buf, size, "%d bit", kBitDepths[BraidsEngine::bitDepthIndex(v)]);
}
void formatRate(float v, char* buf, size_t size) {
  std::snprintf(buf, size, "%d kHz", kRatesKHz[BraidsEngine::sampleRateIndex(v)]);
}

const EngineParamInfo kParams[7] = {
    {"Shape", 0.5f / 47.0f, formatShape},
    {"Timbre", 0.5f, formatPercent},
    {"Color", 0.5f, formatPercent},
    {"Frequency", 0.5f, formatSemitones},
    {"Signature", 0.0f, formatPercent},
    {"Bit Depth", 6.5f / 7.0f, formatBits},
    {"Sample Rate", 6.5f / 7.0f, formatRate},
};

const EngineInfo kInfo = {"braids", "Digital Oscillator", 7, kParams, false};

}  // namespace

struct BraidsEngine::Impl {
  braids::MacroOscillator osc;
  braids::SignatureWaveshaper waveshaper;
  uint8_t sync[kNativeBlock];
  int16_t buffer[kNativeBlock];
  int16_t held;
};

BraidsEngine::BraidsEngine() : impl_(std::make_unique<Impl>()) { reset(); }

BraidsEngine::~BraidsEngine() = default;

const EngineInfo& BraidsEngine::staticInfo() { return kInfo; }

const EngineInfo& BraidsEngine::info() const { return kInfo; }

int BraidsEngine::shapeIndex(float normalized) { return stepIndex(normalized, kNumShapes); }
int BraidsEngine::bitDepthIndex(float normalized) { return stepIndex(normalized, 7); }
int BraidsEngine::sampleRateIndex(float normalized) { return stepIndex(normalized, 7); }
float BraidsEngine::frequencyOffset(float normalized) { return (clamp01(normalized) - 0.5f) * 24.0f; }

void BraidsEngine::prepare(double hostRate, int) {
  pitchOffset_ = float(12.0 * std::log2(kNativeRate / hostRate));
  reset();
}

void BraidsEngine::reset() {
  // MacroOscillator::Init() leaves shape, pitch and parameters unset.
  std::memset(static_cast<void*>(&impl_->osc), 0, sizeof(impl_->osc));
  impl_->osc.Init();
  impl_->waveshaper.Init(0x0000);
  std::memset(impl_->sync, 0, sizeof(impl_->sync));
  impl_->held = 0;
  gate_ = false;
  strike_ = false;
  gain_ = 0.0f;
}

void BraidsEngine::noteOn(float note, float velocity) {
  note_ = note;
  velocity_ = clamp01(velocity);
  gate_ = true;
  strike_ = true;
}

void BraidsEngine::noteOff() { gate_ = false; }

void BraidsEngine::process(const float* const*, float* const* out, const ParamValues& p, int n) {
  for (int done = 0; done < n;) {
    const int count = std::min(kNativeBlock, n - done);
    renderBlock(p, out, done, count);
    done += count;
  }
}

void BraidsEngine::renderBlock(const ParamValues& p, float* const* out, int offset, int count) {
  Impl& s = *impl_;
  s.osc.set_shape(braids::MacroOscillatorShape(shapeIndex(p.p[0])));
  s.osc.set_parameters(int16_t(clamp01(p.p[1]) * 32767.0f), int16_t(clamp01(p.p[2]) * 32767.0f));
  const int pitch = int(std::lround((note_ + frequencyOffset(p.p[3]) + pitchOffset_) * 128.0f));
  s.osc.set_pitch(int16_t(std::clamp(pitch, 0, 16383)));
  if (strike_) {
    s.osc.Strike();
    strike_ = false;
  }
  s.osc.Render(s.sync, s.buffer, size_t(count));

  const uint16_t mask = kBitMasks[bitDepthIndex(p.p[5])];
  const int decimation = kDecimation[sampleRateIndex(p.p[6])];
  const float sig = clamp01(p.p[4]) * 4.0f;
  const uint16_t signature = uint16_t(std::min(65535.0f, sig * sig * 4095.0f));
  const float target = gate_ ? velocity_ : 0.0f;
  for (int i = 0; i < count; ++i) {
    if (i % decimation == 0) s.held = int16_t(s.buffer[i] & mask);
    const int16_t warped =
        int16_t(std::clamp(s.waveshaper.Transform(s.held), int32_t(-32768), int32_t(32767)));
    const int16_t mixed = stmlib::Mix(s.held, warped, signature);
    gain_ += (target - gain_) * (1.0f / 16.0f);
    if (gain_ < 1e-7f && target == 0.0f) gain_ = 0.0f;
    const float v = float(mixed) / 32768.0f * gain_;
    out[0][offset + i] = v;
    out[1][offset + i] = v;
  }
}

}  // namespace eg13
```

```cpp
                             int n) {
  for (int done = 0; done < n;) {
    const int count = std::min(kNativeBlock, n - done);
    renderBlock(in, p, out, done, count);
    done += count;

void ElementsEngine::renderBlock(const float* const* in, const ParamValues& p, float* const* out,
                                 int offset, int count) {
  Impl& s = *impl_;
  const int model = modelIndex(p.p[0]);
  if (model != model_) {
    s.part.set_resonator_model(elements::ResonatorModel(model));
    model_ = model;
  }
  elements::Patch* patch = s.part.mutable_patch();
  patch->exciter_envelope_shape = 1.0f;
  patch->exciter_bow_level = clamp01(p.p[1]);
  patch->exciter_bow_timbre = 0.5f;
  patch->exciter_blow_level = clamp01(p.p[2]);
  patch->exciter_blow_meta = 0.5f;
  patch->exciter_blow_timbre = 0.5f;
  patch->exciter_strike_level = clamp01(p.p[3]);
  patch->exciter_strike_meta = 0.5f;
  patch->exciter_strike_timbre = 0.5f;
  patch->exciter_signature = 0.0f;
  patch->resonator_geometry = std::min(clamp01(p.p[4]), kMaxKnob);
  patch->resonator_brightness = std::min(clamp01(p.p[5]), kMaxKnob);
  patch->resonator_damping = std::min(clamp01(p.p[6]), kMaxKnob);
  patch->resonator_position = std::min(clamp01(p.p[7]), kMaxKnob);
  patch->space = 0.5f;

  elements::PerformanceState state;
  state.gate = gate_;
  state.note = note_ + pitchOffset_;
  state.modulation = 0.0f;
  state.strength = velocity_;

  for (int i = 0; i < count; ++i) {
    s.strike[i] = in ? 0.5f * (in[0][offset + i] + in[1][offset + i]) : 0.0f;
  }
  s.part.Process(state, s.blow, s.strike, s.main, s.aux, size_t(count));
  for (int i = 0; i < count; ++i) {
    out[0][offset + i] = s.aux[i];
    out[1][offset + i] = s.main[i];
  }
}
```

```cpp
struct RingsEngine::Impl {
  rings::Part part;
  uint16_t reverb[32768];
  float in[kNativeBlock];
  float odd[kNativeBlock];
  float even[kNativeBlock];
};

RingsEngine::RingsEngine() : impl_(std::make_unique<Impl>()) { reset(); }

RingsEngine::~RingsEngine() = default;

const EngineInfo& RingsEngine::staticInfo() { return kInfo; }

const EngineInfo& RingsEngine::info() const { return kInfo; }

int RingsEngine::modelIndex(float normalized) {
  const int i = int(clamp01(normalized) * float(kNumModels));
  return i < kNumModels ? i : kNumModels - 1;
}

int RingsEngine::exciterIndex(float normalized) { return clamp01(normalized) >= 0.5f ? 1 : 0; }

float RingsEngine::frequencyOffset(float normalized) { return (clamp01(normalized) - 0.5f) * 24.0f; }

void RingsEngine::prepare(double hostRate, int) {
  pitchOffset_ = float(12.0 * std::log2(kNativeRate / hostRate));
  reset();
}

void RingsEngine::reset() {
  // Part::Init() leaves several members (step counter, voice count) unset.
  std::memset(static_cast<void*>(&impl_->part), 0, sizeof(impl_->part));
  impl_->part.Init(impl_->reverb);
  impl_->part.set_polyphony(1);
  strum_ = false;
  model_ = -1;
}

void RingsEngine::noteOn(float note, float velocity) {
  note_ = note;
  velocity_ = clamp01(velocity);
  strum_ = true;
}

void RingsEngine::process(const float* const* in, float* const* out, const ParamValues& p, int n) {
  for (int done = 0; done < n;) {
    const int count = std::min(kNativeBlock, n - done);
    renderBlock(in, p, out, done, count);
    done += count;
  }
}

void RingsEngine::renderBlock(const float* const* in, const ParamValues& p, float* const* out,
                              int offset, int count) {
  Impl& s = *impl_;
  const int model = modelIndex(p.p[0]);
  if (model != model_) {
    s.part.set_model(rings::ResonatorModel(model));
    model_ = model;
  }
  rings::Patch patch;
  patch.structure = std::min(clamp01(p.p[1]), kMaxKnob);
  patch.brightness = clamp01(p.p[2]);
  patch.damping = std::min(clamp01(p.p[3]), kMaxKnob);
  patch.position = std::min(clamp01(p.p[4]), kMaxKnob);

  const bool external = exciterIndex(p.p[5]) == 1 && in != nullptr;
  rings::PerformanceState state;
  state.strum = strum_;
  state.internal_exciter = !external;
  state.internal_strum = false;
  state.internal_note = true;
  state.tonic = note_ + frequencyOffset(p.p[6]) + pitchOffset_;
  state.note = 0.0f;
  state.fm = 0.0f;
  state.chord = std::clamp(int(std::lround(patch.structure * 10.0f)), 0, 10);
  strum_ = false;

  for (int i = 0; i < count; ++i) {
    s.in[i] = external ? 0.5f * (in[0][offset + i] + in[1][offset + i]) : 0.0f;
  }
  std::memset(s.odd, 0, sizeof(s.odd));
  std::memset(s.even, 0, sizeof(s.even));
  s.part.Process(state, patch, s.in, s.odd, s.even, size_t(count));

  const float spread = clamp01(p.p[7]);
  for (int i = 0; i < count; ++i) {
    out[0][offset + i] = (s.odd[i] + (1.0f - spread) * s.even[i]) * velocity_;
    out[1][offset + i] = (s.even[i] + (1.0f - spread) * s.odd[i]) * velocity_;
  }
}
```

```cpp
#include <cmath>
#include <cstdio>

namespace eg13 {

namespace {

void formatGain(float v, char* buf, size_t size) {
  std::snprintf(buf, size, "%+.1f dB", double(AudioInputEngine::gainDb(v)));
}
void formatTime(float seconds, char* buf, size_t size) {
  if (seconds < 1.0f) {
    std::snprintf(buf, size, "%d ms", int(std::lround(seconds * 1000.0f)));
  } else {
    std::snprintf(buf, size, "%.2f s", double(seconds));
  }
}
void formatAttack(float v, char* buf, size_t size) {
  formatTime(AudioInputEngine::attackSeconds(v), buf, size);
}
void formatRelease(float v, char* buf, size_t size) {
  formatTime(AudioInputEngine::releaseSeconds(v), buf, size);
}

const float kDefaultGain = 24.0f / 36.0f;                                    // 0 dB
const float kDefaultAttack = float(std::log(5.0) / std::log(2000.0));        // 5 ms
const float kDefaultRelease = float(std::log(10.0) / std::log(1000.0));      // 50 ms

const EngineParamInfo kParams[3] = {
    {"Gain", kDefaultGain, formatGain},
    {"Attack", kDefaultAttack, formatAttack},
    {"Release", kDefaultRelease, formatRelease},
};

const EngineInfo kInfo = {"input", "Audio Input", 3, kParams, true};

}  // namespace

const EngineInfo& AudioInputEngine::staticInfo() { return kInfo; }

const EngineInfo& AudioInputEngine::info() const { return kInfo; }

float AudioInputEngine::gainDb(float normalized) { return -24.0f + 36.0f * clamp01(normalized); }

float AudioInputEngine::attackSeconds(float normalized) {
  return 0.001f * std::pow(2000.0f, clamp01(normalized));
}

float AudioInputEngine::releaseSeconds(float normalized) {
  return 0.005f * std::pow(1000.0f, clamp01(normalized));
}

void AudioInputEngine::prepare(double hostRate, int) {
  rate_ = hostRate;
  reset();
}

void AudioInputEngine::reset() {
  gate_ = false;
  envelope_ = 0.0f;
}

void AudioInputEngine::noteOn(float, float velocity) {
  velocity_ = clamp01(velocity);
  gate_ = true;
}

void AudioInputEngine::process(const float* const* in, float* const* out, const ParamValues& p,
                               int n) {
  const float gain = std::pow(10.0f, gainDb(p.p[0]) / 20.0f);
  const float attack = 1.0f - float(std::exp(-1.0 / (double(attackSeconds(p.p[1])) * rate_)));
  const float release = 1.0f - float(std::exp(-1.0 / (double(releaseSeconds(p.p[2])) * rate_)));
  const float target = gate_ ? velocity_ : 0.0f;
  for (int i = 0; i < n; ++i) {
    const float coeff = target > envelope_ ? attack : release;
    envelope_ += (target - envelope_) * coeff;
    if (std::fabs(target - envelope_) < 1e-6f) envelope_ = target;
    const float g = gain * envelope_;
    out[0][i] = in ? in[0][i] * g : 0.0f;
    out[1][i] = in ? in[1][i] * g : 0.0f;
  }
}

}  // namespace eg13
```

```cpp
void Synth::loadParams(const ParamSnapshot& values, const EngineStash* stash) {
  ParamSnapshot clamped{};
  for (size_t i = 0; i < kParamCount; ++i) clamped[i] = clampParam(i, double(values[i]));
  const EngineStash s = stash ? *stash : defaultStash();
  if (!active_.load(std::memory_order_acquire)) {  // no audio thread can run
    store(clamped);
    for (size_t i = 0; i < kStashSize; ++i) stash_[i].store(s[i], std::memory_order_relaxed);
    for (int part = 0; part < kNumParts; ++part) {
      currentEngine_[size_t(part)] = sourceEngineFromSelector(clamped[sourceEngineParamIndex(part)]);
    }
    pendingState_.store(kIdle, std::memory_order_release);
    return;
  }
  for (;;) {
    int expected = kReady;
    if (pendingState_.compare_exchange_strong(expected, kWriting, std::memory_order_acq_rel)) break;
    expected = kIdle;
    if (pendingState_.compare_exchange_strong(expected, kWriting, std::memory_order_acq_rel)) break;
    std::this_thread::yield();  // kApplying: the audio thread is copying the values
  }
  pendingValues_ = clamped;
  pendingStash_ = s;
  pendingHasStash_ = true;
  pendingState_.store(kReady, std::memory_order_release);
}

void Synth::applyPending() {  // audio thread, or main thread while inactive
  int expected = kReady;
  if (!pendingState_.compare_exchange_strong(expected, kApplying, std::memory_order_acq_rel)) return;
  store(pendingValues_);
  if (pendingHasStash_) {
    for (size_t i = 0; i < kStashSize; ++i) stash_[i].store(pendingStash_[i], std::memory_order_relaxed);
  }
  for (int part = 0; part < kNumParts; ++part) {
    currentEngine_[size_t(part)] = sourceEngineFromSelector(pendingValues_[sourceEngineParamIndex(part)]);
  }
  pendingState_.store(kIdle, std::memory_order_release);
}

EngineStash Synth::engineStash() const {
  EngineStash s{};
  const bool pending = hasPending();
  for (size_t i = 0; i < kStashSize; ++i) {
    s[i] = pending ? pendingStash_[i] : stash_[i].load(std::memory_order_relaxed);
  }
  for (int part = 0; part < kNumParts; ++part) {
    const int e = engine(part);
    for (int p = 0; p < int(kSourceParamCount); ++p) {
      s[stashIndex(part, e, p)] = float(param(paramSpec(sourceParamIndex(part, p)).id));
    }
  }
  return s;
}

int Synth::takeHostUpdates(HostUpdate* out, int max) {
  const int count = std::min(max, hostUpdateCount_);
  for (int i = 0; i < count; ++i) out[i] = hostUpdates_[i];

void Synth::switchEngines() {
  for (int part = 0; part < kNumParts; ++part) {
    const int next = sourceEngineFromSelector(load(sourceEngineParamIndex(part)));
    const int previous = currentEngine_[size_t(part)];
    if (next == previous) continue;
    for (int p = 0; p < int(kSourceParamCount); ++p) {
      const size_t index = sourceParamIndex(part, p);
      stash_[stashIndex(part, previous, p)].store(load(index), std::memory_order_relaxed);
      const float value = stash_[stashIndex(part, next, p)].load(std::memory_order_relaxed);
      values_[index].store(value, std::memory_order_relaxed);
      if (hostUpdateCount_ < int(2 * kSourceParamCount)) {
        hostUpdates_[hostUpdateCount_++] = {paramSpec(index).id, value};
      }
    }
    currentEngine_[size_t(part)] = next;
    engineChanged_.store(true, std::memory_order_release);
  }
}

float Synth::softLimit(float x) {
  const float a = std::fabs(x);
  if (a <= 1.0f) return x;
  const float d = a - 1.0f;
  return std::copysign(1.0f + d / (1.0f + d), x);
}

void Synth::routeInput(int part, const float* const* in, int n) {
  const int source = std::clamp(parts_[size_t(part)]->settings().inputSource, 0, 2);
  const bool external = (source == 0 || source == 2) && in != nullptr;
  const bool other = source >= 1;
  for (int ch = 0; ch < 2; ++ch) {
    float* dst = partIn_[part][ch].data();
    for (int i = 0; i < n; ++i) {
      float v = external ? in[ch][i] : 0.0f;
      if (other) {
        const float feed = part == 0 ? (i < previousBCount_ ? previousB_[ch][size_t(i)] : 0.0f)
                                     : partOut_[0][ch][size_t(i)];
        v += softLimit(feed);
      }
      dst[i] = v;
    }
  }
}
```

```cpp
    synth.setActive(false);
  }
  REQUIRE(worst < 50.0);
}
```
