# EG13 M0 (Skeleton) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a monophonic Plaits ("Macro Oscillator") synth as two plugins (EG13 instrument and EG13 FX), shipped from one CLAP bundle with AU v2, VST3 and Standalone builds, plus tests, validators and CI.

**Architecture:** A portable C++17 core (`/core`) wraps the unmodified upstream Plaits DSP behind the spec's `VoiceEngine` interface. A `Synth` class adds a mono note stack, parameter storage and the FX input path. A thin C++ CLAP plugin (`/plugin`) exposes two plugin IDs from one factory. clap-wrapper turns that into AU v2 (`aumu` + `aumf`), VST3 and Standalone. There is no custom UI yet: hosts show their generic parameter UI.

**Tech Stack:** C++17, CMake ≥ 3.21 + Ninja, Catch2 v3, nlohmann/json (single header), free-audio/clap 1.2.10, clap-wrapper v0.16.0, pichenettes/eurorack (Plaits + stmlib), clap-validator, auval, pluginval, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-20-eg13-design.md` (milestone M0, §11).

## Global Constraints

- EG13 is GPL-3.0. Never use "Mutable Instruments" in product name, UI or marketing. Engine display names are traditional; Plaits is shown as **"Macro Oscillator"**.
- macOS 13+ deployment target, universal binary (arm64 + x86_64). C++17.
- `/core` has no OS, plugin or UI dependencies and must build and test on macOS and Linux.
- The audio thread never allocates, locks or waits. Allocation happens only in constructors and `prepare`.
- `third_party/eurorack` stays unmodified. Every translation unit that includes eurorack headers is compiled with `TEST` defined (stmlib selects portable code instead of ARM assembly with it).
- Parameter IDs are stable and never renumbered: `id = (part << 16) | (slot << 8) | index`, where index 0 is the engine/type selector and 1..n are P1..Pn.
- The plugin display name is the CMake cache variable `EG13_DISPLAY_NAME` (default `EG13`), separate from the codename.
- Permanent identifiers (never change after release): CLAP IDs `com.symbioticaudio.eg13` and `com.symbioticaudio.eg13.fx`; AU manufacturer `Symb`; AU subtypes `EG13` (`aumu`) and `EGfx` (`aumf`).

## Scope notes (M0 vs. later milestones)

These are deliberate M0 simplifications. Each is replaced in the milestone named:
- **Sample rate:** Plaits runs at the host rate with a pitch correction (`12·log2(48000/hostRate)` semitones). Timbre is very slightly off at rates other than 48 kHz. M1 replaces this with `NativeRateWrapper` (r8brain).
- **Plaits Model:** exposed as the automatable P1 (the hardware also has CV over model). No engine selector yet, since there is only one source engine.
- **FX plugin:** output = input + synth. Dry level, Always-on trigger and the sidechain come in M1.
- **No custom UI and no `/core-api`.** The plugin calls the C++ `Synth` directly. The C API comes with M1/M6.
- **State:** a flat parameter map with `schemaVersion`. Preserving unknown data on resave comes in M1.

## Review Focus

1. **Host sample rate ≠ 48 kHz** (44.1, 88.2, 96, 192 kHz): notes must still play in tune. Pinned in Task 3 ("tracks pitch at other host rates").
2. **Host buffer layout:** odd block sizes (1, 7, not multiples of 12), events in the middle of a block, and FX hosts passing the same buffer for input and output. Output must be identical however the block is sliced, and FX passthrough must survive in-place buffers. Pinned in Task 3 ("independent of block size") and Task 5 ("event timing is independent of block slicing", "FX passthrough survives in-place buffers").
3. **Overlapping held notes on a mono synth:** releasing keys in any order plays the most recent still-held note, and releasing the last key closes the gate. Pinned in Tasks 4 and 5.
4. **Saved state that is corrupted, from a newer version, or with unknown or missing parameters:** load what is understood, never crash, and leave the current sound untouched when the data is unusable. Pinned in Task 6.
5. **Out-of-range or NaN parameter values from hosts and automation:** values are clamped or ignored, and the audio is never NaN. Pinned in Task 3 ("parameter values are clamped") and Task 5 ("setParam clamps and rejects NaN").

```cpp
#pragma once

#include <cstdint>

namespace eg13::params {

// Stable parameter IDs: (part << 16) | (slot << 8) | index.
// Index 0 is the slot's engine/type selector; 1..n are P1..Pn.
// IDs are saved in projects and presets and must never be renumbered.
enum class Slot : uint32_t {
  Part = 0,
  Source = 1,
  Filter = 2,
  Shaper = 3,
  PartFx = 4,
  Mod1 = 5,
  Mod2 = 6,
  Mod3 = 7,
  Mod4 = 8,
  Matrix = 9,
};

constexpr uint32_t kMasterPart = 0xFF;

constexpr uint32_t id(uint32_t part, Slot slot, uint32_t index) {
  return (part << 16) | (uint32_t(slot) << 8) | index;
}

constexpr uint32_t kMasterLevel = id(kMasterPart, Slot::Part, 0);

}  // namespace eg13::params
```

```cpp
#pragma once

#include <cstddef>

namespace eg13 {

constexpr int kMaxSlotParams = 8;

// Post-modulation slot parameter values, normalized 0..1.
struct ParamValues {
  float p[kMaxSlotParams] = {};
};

using ParamFormatter = void (*)(float normalized, char* buf, size_t size);

struct EngineParamInfo {
  const char* name;
  float defaultValue;
  ParamFormatter format;
};

struct EngineInfo {
  const char* id;           // stable, saved in state
  const char* displayName;  // shown in the UI
  int paramCount;
  const EngineParamInfo* params;
};

// Per-voice sound generator or processor (Source, Filter, Shaper slots).
class VoiceEngine {
 public:
  virtual ~VoiceEngine() = default;
  // Main thread, never concurrently with process(). The only place that may allocate.
  virtual void prepare(double hostRate, int maxBlock) = 0;
  virtual void reset() = 0;
  virtual void noteOn(float note, float velocity) = 0;  // note: float MIDI note
  virtual void noteOff() = 0;
  // out[0], out[1]: n samples each. in may be nullptr.
  virtual void process(const float* const* in, float* const* out,
                       const ParamValues& p, int n) = 0;
  virtual const EngineInfo& info() const = 0;
};

inline float clamp01(float x) {
  if (!(x > 0.0f)) return 0.0f;  // also maps NaN to 0
  return x > 1.0f ? 1.0f : x;
}

}  // namespace eg13
```

```cpp
#pragma once

#include <cmath>
#include <cstddef>
#include <vector>

#include "engine/voice_engine.h"

namespace eg13::test {

inline ParamValues defaultParams(const EngineInfo& info) {
  ParamValues p;
  for (int i = 0; i < info.paramCount; ++i) p.p[i] = info.params[i].defaultValue;
  return p;
}

// Fundamental from rising zero crossings (linearly interpolated) in [start, end).
inline double estimateFrequency(const std::vector<float>& x, double rate,
                                size_t start, size_t end) {
  double first = -1.0;
  double last = -1.0;
  int crossings = 0;
  for (size_t i = start + 1; i < end; ++i) {
    if (x[i - 1] < 0.0f && x[i] >= 0.0f) {
      const double t = double(i - 1) + double(-x[i - 1]) / double(x[i] - x[i - 1]);
      if (first < 0.0) first = t;
      last = t;
      ++crossings;
    }
  }
  if (crossings < 2) return 0.0;
  return double(crossings - 1) * rate / (last - first);
}

inline double rms(const std::vector<float>& x, size_t start, size_t end) {
  double sum = 0.0;
  for (size_t i = start; i < end; ++i) sum += double(x[i]) * double(x[i]);
  return end > start ? std::sqrt(sum / double(end - start)) : 0.0;
}

}  // namespace eg13::test
```

```cpp
struct PlaitsEngine::Impl {
  plaits::Voice voice;
  char ram[kRamSize];
  plaits::Voice::Frame frames[plaits::kBlockSize];
};

PlaitsEngine::PlaitsEngine() : impl_(std::make_unique<Impl>()) { reset(); }

PlaitsEngine::~PlaitsEngine() = default;

const EngineInfo& PlaitsEngine::staticInfo() { return kInfo; }

const EngineInfo& PlaitsEngine::info() const { return kInfo; }

int PlaitsEngine::modelIndex(float normalized) {
  const int index = int(clamp01(normalized) * float(kNumModels));
  return index < kNumModels ? index : kNumModels - 1;
}

float PlaitsEngine::frequencyOffset(float normalized) {
  return (clamp01(normalized) - 0.5f) * 24.0f;
}

void PlaitsEngine::prepare(double hostRate, int) {
  pitchOffset_ = float(12.0 * std::log2(double(kNativeRate) / hostRate));
  reset();
}

void PlaitsEngine::reset() {
  stmlib::BufferAllocator allocator(impl_->ram, kRamSize);
  impl_->voice.Init(&allocator);
  gate_ = false;
  retrigger_ = false;
  pos_ = plaits::kBlockSize;
}

void PlaitsEngine::noteOn(float note, float velocity) {
  note_ = note;
  velocity_ = clamp01(velocity);
  gate_ = true;
  retrigger_ = true;
}

void PlaitsEngine::noteOff() { gate_ = false; }

void PlaitsEngine::renderBlock(const ParamValues& p) {
  plaits::Patch patch = {};
  patch.note = note_ + frequencyOffset(p.p[4]) + pitchOffset_;
  patch.harmonics = clamp01(p.p[1]);
  patch.timbre = clamp01(p.p[2]);
  patch.morph = clamp01(p.p[3]);
  patch.engine = modelIndex(p.p[0]);
  patch.decay = clamp01(p.p[5]);
  patch.lpg_colour = clamp01(p.p[6]);

  plaits::Modulations mods = {};
  mods.trigger_patched = true;
  mods.level_patched = true;
  // A low block before a new note gives Plaits a rising edge even when the
  // gate was already high (mono retrigger).
  mods.trigger = (gate_ && !retrigger_) ? 1.0f : 0.0f;
  mods.level = gate_ ? velocity_ : 0.0f;
  retrigger_ = false;

  impl_->voice.Render(patch, mods, impl_->frames, plaits::kBlockSize);
}

void PlaitsEngine::process(const float* const*, float* const* out, const ParamValues& p,
                           int n) {
  const float aux = clamp01(p.p[7]);
  for (int i = 0; i < n; ++i) {
    if (pos_ == plaits::kBlockSize) {
      renderBlock(p);
      pos_ = 0;
    }
    const plaits::Voice::Frame& f = impl_->frames[pos_++];
    const float s = ((1.0f - aux) * float(f.out) + aux * float(f.aux)) / 32768.0f;
    out[0][i] = s;
    out[1][i] = s;
  }
}
```

```cpp
#pragma once

namespace eg13 {

// Last-note-priority stack of held keys. Fixed capacity, no allocation.
class MonoNoteStack {
 public:
  static constexpr int kCapacity = 16;

  void noteOn(int key, float velocity) {
    remove(key);
    if (size_ == kCapacity) removeAt(0);
    entries_[size_++] = {key, velocity};
  }

  void noteOff(int key) { remove(key); }
  void clear() { size_ = 0; }
  bool empty() const { return size_ == 0; }
  int size() const { return size_; }
  int topKey() const { return entries_[size_ - 1].key; }          // requires !empty()
  float topVelocity() const { return entries_[size_ - 1].velocity; }  // requires !empty()

 private:
  struct Entry {
    int key;
    float velocity;
  };

  void remove(int key) {
    for (int i = 0; i < size_; ++i) {
      if (entries_[i].key == key) {
        removeAt(i);
        return;
      }
    }
  }

  void removeAt(int index) {
    for (int i = index; i < size_ - 1; ++i) entries_[i] = entries_[i + 1];
    --size_;
  }

  Entry entries_[kCapacity] = {};
  int size_ = 0;
};

}  // namespace eg13
```

```cpp
Synth::Synth(PluginKind kind) : kind_(kind) { resetParamsToDefaults(); }

void Synth::prepare(double sampleRate, int maxBlock) {

  notes_.clear();
}

void Synth::reset() {
  engine_.reset();
  notes_.clear();
}

void Synth::noteOn(int key, float velocity) {
  notes_.noteOn(key, velocity);
  engine_.noteOn(float(key), velocity);
}

void Synth::noteOff(int key) {
  const bool wasTop = !notes_.empty() && notes_.topKey() == key;
  notes_.noteOff(key);
  if (notes_.empty()) {
    engine_.noteOff();
  } else if (wasTop) {
    engine_.noteOn(float(notes_.topKey()), notes_.topVelocity());
  }
}

void Synth::allNotesOff() {
  notes_.clear();
  engine_.noteOff();
}

bool Synth::setParam(uint32_t id, double value) {
  const int index = paramIndex(id);
  if (index < 0 || std::isnan(value)) return false;
  values_[size_t(index)].store(float(std::clamp(value, 0.0, 1.0)), std::memory_order_relaxed);
  return true;
}

double Synth::param(uint32_t id) const {
  const int index = paramIndex(id);
  return index < 0 ? 0.0 : double(load(size_t(index)));
}

void Synth::resetParamsToDefaults() {
  for (size_t i = 0; i < kParamCount; ++i) {
    values_[i].store(paramSpec(i).defaultValue, std::memory_order_relaxed);
  }
}

void Synth::process(const float* const* in, float* const* out, int n) {
  ParamValues p;
  for (size_t i = 0; i < kSourceParamCount; ++i) p.p[i] = load(i);
  const float gain = load(kMasterLevelIndex);
  const bool addInput = kind_ == PluginKind::Effect && in != nullptr;

  for (int done = 0; done < n;) {
    const int count = std::min(kChunk, n - done);
    if (addInput) {
      // Copy first: the host may pass the same buffer for input and output.
      std::memcpy(input_[0], in[0] + done, size_t(count) * sizeof(float));
      std::memcpy(input_[1], in[1] + done, size_t(count) * sizeof(float));
    }
    float* r[2] = {render_[0], render_[1]};
    engine_.process(nullptr, r, p, count);
    for (int ch = 0; ch < 2; ++ch) {
      for (int i = 0; i < count; ++i) {
        float v = render_[ch][i] * gain;
        if (addInput) v += input_[ch][i];
        out[ch][done + i] = v;
      }
    }
    done += count;
  }
}

}  // namespace eg13
```

```cpp
#include <cstdint>
#include <cstdlib>
#include <utility>
#include <vector>

#include <nlohmann/json.hpp>

#include "synth/param_table.h"
#include "synth/synth.h"

namespace eg13::state {

namespace {

bool parseId(const std::string& key, uint32_t* id) {
  if (key.empty() || key.size() > 10) return false;
  for (char c : key) {
    if (c < '0' || c > '9') return false;
  }
  const unsigned long long value = std::strtoull(key.c_str(), nullptr, 10);
  if (value > 0xFFFFFFFFull) return false;
  *id = uint32_t(value);
  return true;
}

}  // namespace

std::string save(const Synth& synth) {
  nlohmann::json params = nlohmann::json::object();
  for (size_t i = 0; i < kParamCount; ++i) {
    const uint32_t id = paramSpec(i).id;
    params[std::to_string(id)] = synth.param(id);
  }
  nlohmann::json root = nlohmann::json::object();
  root["schemaVersion"] = kSchemaVersion;
  root["params"] = std::move(params);
  return root.dump();
}

LoadResult load(Synth& synth, const std::string& json) {
  const nlohmann::json root = nlohmann::json::parse(json, nullptr, false);
  if (root.is_discarded() || !root.is_object()) return LoadResult::Invalid;

  const auto version = root.find("schemaVersion");
  const auto params = root.find("params");
  if (version == root.end() || !version->is_number_integer() || params == root.end() ||
      !params->is_object()) {
    return LoadResult::Invalid;
  }
  const long long schema = version->get<long long>();
  if (schema < 1) return LoadResult::Invalid;
  bool warnings = schema > kSchemaVersion;

  std::vector<std::pair<uint32_t, double>> values;
  for (auto it = params->begin(); it != params->end(); ++it) {
    uint32_t id = 0;
    if (!parseId(it.key(), &id) || !it.value().is_number() || paramIndex(id) < 0) {
      warnings = true;
      continue;
    }
    values.emplace_back(id, it.value().get<double>());
  }

  synth.resetParamsToDefaults();
  for (const auto& [id, value] : values) {
    if (!synth.setParam(id, value)) warnings = true;
  }
  return warnings ? LoadResult::OkWithWarnings : LoadResult::Ok;
}

}  // namespace eg13::state
```

```cpp
#include <cstring>
#include <string>

#include "state/state.h"
#include "synth/param_table.h"

namespace eg13 {

namespace {

struct Plugin {
  Plugin(const clap_host_t* h, PluginKind k) : host(h), kind(k), synth(k) {}
  clap_plugin_t clap{};
  const clap_host_t* host;
  const clap_host_params_t* hostParams = nullptr;
  PluginKind kind;
  Synth synth;
};

Plugin* self(const clap_plugin_t* p) { return static_cast<Plugin*>(p->plugin_data); }

// ---- events -----------------------------------------------------------------

void handleEvent(Plugin* plugin, const clap_event_header_t* hdr) {
  if (hdr->space_id != CLAP_CORE_EVENT_SPACE_ID) return;
  switch (hdr->type) {
    case CLAP_EVENT_NOTE_ON: {
      const auto* ev = reinterpret_cast<const clap_event_note_t*>(hdr);
      if (ev->key >= 0 && ev->key <= 127) plugin->synth.noteOn(ev->key, float(ev->velocity));
      break;
    }
    case CLAP_EVENT_NOTE_OFF:
    case CLAP_EVENT_NOTE_CHOKE: {
      const auto* ev = reinterpret_cast<const clap_event_note_t*>(hdr);
      if (ev->key < 0) {
        plugin->synth.allNotesOff();
      } else {
        plugin->synth.noteOff(ev->key);
      }
      break;
    }
    case CLAP_EVENT_PARAM_VALUE: {
      const auto* ev = reinterpret_cast<const clap_event_param_value_t*>(hdr);
      plugin->synth.setParam(ev->param_id, ev->value);
      break;
    }
    case CLAP_EVENT_MIDI: {
      const auto* ev = reinterpret_cast<const clap_event_midi_t*>(hdr);
      const uint8_t status = ev->data[0] & 0xF0;
      const int key = ev->data[1] & 0x7F;
      const int velocity = ev->data[2] & 0x7F;
      if (status == 0x90 && velocity > 0) {
        plugin->synth.noteOn(key, float(velocity) / 127.0f);
      } else if (status == 0x80 || status == 0x90) {
        plugin->synth.noteOff(key);
      } else if (status == 0xB0 && (key == 120 || key == 123)) {
        plugin->synth.allNotesOff();
      }
      break;
    }
    default:
      break;
  }
}

// ---- audio ports --------------------------------------------------------------

uint32_t audioPortsCount(const clap_plugin_t* p, bool isInput) {
  if (isInput) return self(p)->kind == PluginKind::Effect ? 1 : 0;
  return 1;
}

bool audioPortsGet(const clap_plugin_t* p, uint32_t index, bool isInput,
                   clap_audio_port_info_t* info) {
  if (index >= audioPortsCount(p, isInput)) return false;
  info->id = isInput ? 0 : 1;
  std::snprintf(info->name, sizeof(info->name), "%s", isInput ? "Input" : "Output");
  info->flags = CLAP_AUDIO_PORT_IS_MAIN;
  info->channel_count = 2;
  info->port_type = CLAP_PORT_STEREO;
  info->in_place_pair = CLAP_INVALID_ID;
  return true;
}

const clap_plugin_audio_ports_t kAudioPorts = {audioPortsCount, audioPortsGet};

// ---- note ports ----------------------------------------------------------------

uint32_t notePortsCount(const clap_plugin_t*, bool isInput) { return isInput ? 1 : 0; }

bool notePortsGet(const clap_plugin_t*, uint32_t index, bool isInput,
                  clap_note_port_info_t* info) {
  if (!isInput || index != 0) return false;
  info->id = 0;
  info->supported_dialects = CLAP_NOTE_DIALECT_CLAP | CLAP_NOTE_DIALECT_MIDI;
  info->preferred_dialect = CLAP_NOTE_DIALECT_CLAP;
  std::snprintf(info->name, sizeof(info->name), "%s", "Notes");
  return true;
}

const clap_plugin_note_ports_t kNotePorts = {notePortsCount, notePortsGet};

// ---- params ----------------------------------------------------------------------

uint32_t paramsCount(const clap_plugin_t*) { return uint32_t(kParamCount); }

bool paramsGetInfo(const clap_plugin_t*, uint32_t index, clap_param_info_t* info) {
  if (index >= kParamCount) return false;
  const ParamSpec& spec = paramSpec(index);
  std::memset(info, 0, sizeof(*info));
  info->id = spec.id;
  info->flags = CLAP_PARAM_IS_AUTOMATABLE;
  info->cookie = nullptr;
  std::snprintf(info->name, sizeof(info->name), "%s", spec.name);
  std::snprintf(info->module, sizeof(info->module), "%s", spec.module);
  info->min_value = 0.0;
  info->max_value = 1.0;
  info->default_value = double(spec.defaultValue);
  return true;
}

bool paramsGetValue(const clap_plugin_t* p, clap_id id, double* value) {
  if (paramIndex(id) < 0) return false;
  *value = self(p)->synth.param(id);
  return true;
}

bool paramsValueToText(const clap_plugin_t*, clap_id id, double value, char* display,
                       uint32_t size) {
  const int index = paramIndex(id);
  if (index < 0) return false;
  formatParam(size_t(index), value, display, size);
  return true;
}

bool paramsTextToValue(const clap_plugin_t*, clap_id, const char*, double*) { return false; }

void paramsFlush(const clap_plugin_t* p, const clap_input_events_t* in,
                 const clap_output_events_t*) {
  const uint32_t count = in->size(in);
  for (uint32_t i = 0; i < count; ++i) {
    const clap_event_header_t* hdr = in->get(in, i);
    if (hdr->space_id == CLAP_CORE_EVENT_SPACE_ID && hdr->type == CLAP_EVENT_PARAM_VALUE) {
      handleEvent(self(p), hdr);
    }
  }
}

const clap_plugin_params_t kParams = {paramsCount,       paramsGetInfo, paramsGetValue,
                                      paramsValueToText, paramsTextToValue, paramsFlush};

// ---- state --------------------------------------------------------------------------

bool stateSave(const clap_plugin_t* p, const clap_ostream_t* stream) {
  const std::string data = state::save(self(p)->synth);
  const char* ptr = data.data();
  int64_t remaining = int64_t(data.size());
  while (remaining > 0) {
    const int64_t written = stream->write(stream, ptr, uint64_t(remaining));
    if (written <= 0) return false;
    ptr += written;
    remaining -= written;
  }
  return true;
}

bool stateLoad(const clap_plugin_t* p, const clap_istream_t* stream) {
  std::string data;
  char buffer[4096];
  for (;;) {
    const int64_t read = stream->read(stream, buffer, sizeof(buffer));
    if (read < 0) return false;
    if (read == 0) break;
    data.append(buffer, size_t(read));
  }
  Plugin* plugin = self(p);
  if (state::load(plugin->synth, data) == state::LoadResult::Invalid) return false;
  if (plugin->hostParams) plugin->hostParams->rescan(plugin->host, CLAP_PARAM_RESCAN_VALUES);
  return true;
}

const clap_plugin_state_t kState = {stateSave, stateLoad};

// ---- plugin -------------------------------------------------------------------------

bool pluginInit(const clap_plugin_t* p) {
  Plugin* plugin = self(p);
  plugin->hostParams = static_cast<const clap_host_params_t*>(
      plugin->host->get_extension(plugin->host, CLAP_EXT_PARAMS));
  return true;
}

void pluginDestroy(const clap_plugin_t* p) { delete self(p); }

bool pluginActivate(const clap_plugin_t* p, double sampleRate, uint32_t, uint32_t maxFrames) {
  self(p)->synth.prepare(sampleRate, int(maxFrames));
  return true;
}

void pluginDeactivate(const clap_plugin_t*) {}
bool pluginStartProcessing(const clap_plugin_t*) { return true; }
void pluginStopProcessing(const clap_plugin_t*) {}
void pluginReset(const clap_plugin_t* p) { self(p)->synth.reset(); }

clap_process_status pluginProcess(const clap_plugin_t* p, const clap_process_t* proc) {
  Plugin* plugin = self(p);
  const uint32_t frames = proc->frames_count;
  const uint32_t numEvents = proc->in_events->size(proc->in_events);

  if (proc->audio_outputs_count < 1 || proc->audio_outputs[0].channel_count < 1 ||
      proc->audio_outputs[0].data32 == nullptr) {
    for (uint32_t i = 0; i < numEvents; ++i) {
      handleEvent(plugin, proc->in_events->get(proc->in_events, i));
    }
    return CLAP_PROCESS_CONTINUE;
  }

  const clap_audio_buffer_t& outBuf = proc->audio_outputs[0];
  float* out[2] = {outBuf.data32[0],
                   outBuf.channel_count > 1 ? outBuf.data32[1] : outBuf.data32[0]};

  const float* in[2] = {nullptr, nullptr};
  const bool hasInput = plugin->kind == PluginKind::Effect && proc->audio_inputs_count > 0 &&
                        proc->audio_inputs[0].data32 != nullptr &&
                        proc->audio_inputs[0].channel_count > 0;
  if (hasInput) {
    const clap_audio_buffer_t& inBuf = proc->audio_inputs[0];
    in[0] = inBuf.data32[0];
    in[1] = inBuf.channel_count > 1 ? inBuf.data32[1] : inBuf.data32[0];
  }

  uint32_t eventIndex = 0;
  uint32_t frame = 0;
  while (frame < frames) {
    uint32_t next = frames;
    while (eventIndex < numEvents) {
      const clap_event_header_t* hdr = proc->in_events->get(proc->in_events, eventIndex);
      if (hdr->time > frame) {
        next = std::min(hdr->time, frames);
        break;
      }
      handleEvent(plugin, hdr);
      ++eventIndex;
    }
    float* outSlice[2] = {out[0] + frame, out[1] + frame};
    if (hasInput) {
      const float* inSlice[2] = {in[0] + frame, in[1] + frame};
      plugin->synth.process(inSlice, outSlice, int(next - frame));
    } else {
      plugin->synth.process(nullptr, outSlice, int(next - frame));
    }
    frame = next;
  }
  while (eventIndex < numEvents) {
    handleEvent(plugin, proc->in_events->get(proc->in_events, eventIndex++));
  }
  return CLAP_PROCESS_CONTINUE;
}

const void* pluginGetExtension(const clap_plugin_t*, const char* id) {
  if (std::strcmp(id, CLAP_EXT_AUDIO_PORTS) == 0) return &kAudioPorts;
  if (std::strcmp(id, CLAP_EXT_NOTE_PORTS) == 0) return &kNotePorts;
  if (std::strcmp(id, CLAP_EXT_PARAMS) == 0) return &kParams;
  if (std::strcmp(id, CLAP_EXT_STATE) == 0) return &kState;
  return nullptr;
}

void pluginOnMainThread(const clap_plugin_t*) {}

}  // namespace

const clap_plugin_t* createPlugin(const clap_host_t* host, PluginKind kind,
                                  const clap_plugin_descriptor_t* descriptor) {
  auto* plugin = new Plugin(host, kind);
  plugin->clap.desc = descriptor;
  plugin->clap.plugin_data = plugin;
  plugin->clap.init = pluginInit;
  plugin->clap.destroy = pluginDestroy;
  plugin->clap.activate = pluginActivate;
  plugin->clap.deactivate = pluginDeactivate;
  plugin->clap.start_processing = pluginStartProcessing;
  plugin->clap.stop_processing = pluginStopProcessing;
  plugin->clap.reset = pluginReset;
  plugin->clap.process = pluginProcess;
  plugin->clap.get_extension = pluginGetExtension;
  plugin->clap.on_main_thread = pluginOnMainThread;
  return &plugin->clap;
}
```

```bash
#!/usr/bin/env bash
# Runs clap-validator, auval (instrument + FX) and pluginval on a mac build.
# Installs the AU component into ~/Library/Audio/Plug-Ins/Components so auval can find it.
set -euo pipefail
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
BUILD="${1:-$ROOT/build/mac}"
PLUGINS="$BUILD/plugins"

"$ROOT/scripts/fetch-validators.sh" >/dev/null
CLAP_VALIDATOR="$(find "$ROOT/build/tools/clap-validator" -type f -name clap-validator | head -1)"
PLUGINVAL="$(find "$ROOT/build/tools/pluginval" -type f -path '*MacOS/pluginval' | head -1)"

CLAP="$(find "$PLUGINS" -maxdepth 1 -name '*.clap' | head -1)"
COMPONENT="$(find "$PLUGINS" -maxdepth 1 -name '*.component' | head -1)"
VST3="$(find "$PLUGINS" -maxdepth 1 -name '*.vst3' | head -1)"

echo "== clap-validator: $CLAP"
"$CLAP_VALIDATOR" validate "$CLAP" --only-failed

echo "== auval: $COMPONENT"
codesign --force --deep --sign - "$COMPONENT"
DEST="$HOME/Library/Audio/Plug-Ins/Components"
mkdir -p "$DEST"
rm -rf "$DEST/$(basename "$COMPONENT")"
cp -R "$COMPONENT" "$DEST/"
killall -9 AudioComponentRegistrar 2>/dev/null || true
auval -a | grep -E "Symb" || true
auval -v aumu EG13 Symb
auval -v aumf EGfx Symb

echo "== pluginval: $VST3"
codesign --force --deep --sign - "$VST3"
"$PLUGINVAL" --strictness-level 5 --validate-in-process --validate "$VST3"

echo "All validators passed."
```
