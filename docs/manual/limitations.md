# Known limitations

- **Levels:** each voice plays 12 dB lower (Voice Gain) and the Sources are trimmed to similar levels, so an eight-note chord of the init patch peaks around full scale (measured: Macro Oscillator 1.0, Digital Oscillator 0.94, Modal Synth 0.57). The Soft Clip on the outputs keeps louder material within full scale, gently. Some Filter and Shaper settings are still much louder than their input (Classic Filters at full Resonance about +13 dB, the EQ at its extremes, the Ring Mod / Vocoder up to +12 dB at *Fold*); turn the master level down, or let the Soft Clip catch them.
- **Editor, coming in the next version (M6b):** a Motion row does not yet open its route (the matrix editor is not built); the matrix has no source and destination choices (routes keep the ones they have and only their amounts can be set; Custom envelope shapes cannot be changed); there is no collapsible on-screen keyboard and no keyboard focus navigation between knobs; the cog panel offers only the window size and About (the full settings and about screens come later); and a knob's context menu has no "Modulate from..." entry. Saved projects keep whatever routes they hold. Presets arrive in M7.
- **MPE configuration:** EG13 does not read the MPE Configuration Message; set the zones with each part's *MPE* setting. A key held on two channels at once shares one voice.
- **Note expressions:** of CLAP's per-note expressions, EG13 uses Tuning, Pressure and Brightness; Volume, Pan, Vibrato and Expression are ignored for now.
- **Resonator velocity:** with Polyphony 2 or 4, a new note's velocity also changes the level of earlier notes still ringing (fading in with a time constant of 5 ms, without a click). A level per string would need a change inside the original module's code.
- **Modal Synth input:** the firmware's noise gate on the external input is not ported.
- **Granular Delay scope:** the module's automatic input level is left out, as EG13's own levels set the input (the input enters at unity and is clipped at full scale: hard in *Digital*, *Vintage digital* and *Clean tape*, soft in *Dirty tape*, as the module's manual-level path does). Its wavetable synth mode, assignable CV input, gate output and mono buffer setting are left out too: the effect always runs in stereo, with the buffer lengths of stereo.
- **Granular Delay, Dirty tape and silence:** the module's soft clipping adds a tiny constant offset to the input (about a quarter of a percent of full scale) that, with nothing playing, the module's own grains and reverb would keep turning into a quiet pulsing hiss that never dies away. EG13 removes that offset, so silence in is silence out once the tail has faded; loud sound is unchanged apart from that offset.
- **Part B in Single mode** still runs and uses CPU, so it can feed Part A.
- **Ring Mod / Vocoder noise carrier:** with Osc Shape *Saw / Noise* in the vocoder range, the noise comes from a random generator shared by the voices on one audio thread, so two renders of the same notes are not sample-identical.
- **Function Generator randomness:** its *Random* mode and its LFO's *Noise* waveform draw from one random generator shared by every EG13 instance in the host (the module's own code keeps one for the whole module), so two renders of the same notes are not sample-identical. Random / S&H has its own generator in each slot.
- **CPU:** sixteen voices (two parts of eight) of the heaviest chain with a mono Source, Resonator → Analog Filter → Vocoder, use 49.5 % of one Apple M1 core (49.46 % measured; Macro Oscillator → Analog Filter → Vocoder is within a point, 48.96 %) when the Ring Mod / Vocoder's Carrier and Modulator are the internal oscillator or the voice. That is within the budget of half a core. With side inputs carrying a signal the same Resonator chain uses 50.4 % with one (Modulator *Input*), just over, and 51.4 % with two (Carrier *Source AUX*, Modulator *Input*), **over** that budget. With a stereo Source (Modal Synth, Resonator with Spread, a stereo input), every Filter and Shaper runs twice, and the heaviest stereo chain uses 90.0 % (Modal Synth → Analog Filter → Vocoder). Engines that run at their own sample rate save work by converting a side input only while it carries a signal, and the right channel only while it differs from the left; this changes nothing you can hear. When a voice turns stereo, or a side input starts after silence, the conversion restarts with a short burst of extra work in that one block. EG13 checks each conversion path when the plugin is prepared and skips only where the restarted conversion is proven identical; should a restart still come back out of step while playing, that engine restarts all its conversions at once, which leaves a one-off silent gap about as long as its latency (a few milliseconds) and keeps it in time with the rest of the voice; a held note keeps sounding after the gap. That conversion path then stops skipping until the plugin is prepared again; the engine's other paths are unaffected. Modulation adds 7 to 9 % of a core when every mod slot of every voice is in use (measured on an M1; budget 10 %). Part FX adds up to 2.7 % when both parts run their costliest effect (budget 5 %: Granular Delay in Live, Granular in Studio), and the part FX of a part also carries about 1.5 MB of memory. See the README for the measured figures.
- **Part FX delay with Part FX Off:** every part pays the Part FX delay (263 samples, 5.5 ms in Live; 539, 11 ms in Studio at 48 kHz) even with Part FX Off, so that switching the effect never moves the sound in time. See [Latency](latency.md).
- **Part FX levels:** each effect is trimmed to about the level of the part without an effect at its default settings (see [Part FX](part-fx.md)); settings away from the defaults change the level as on the modules (Granular's peaks, for one, run up to about 4 dB above the part without an effect even at the defaults).
- **Classic Filters Model** changes restart the filter and can click on a sounding note.
